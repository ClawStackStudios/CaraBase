# Brand Identity

## Brand Name & Tagline
- **Canonical Product Name**: CaraBase©™
- **Tagline**: "The Core You Actually Use — Your LAN-First, Self-Hosted SQLite DBaaS"
- **Organization**: ClawStack Studios©™
- **Mascot**: 🦞 CrustAgent©™ / Lobster

## Design Language
- **System**: "ClawStack Slate & Cyber Accent"
- **Core Principles**: High-density sovereign developer vault with cryptographic certainty, high-contrast carbon backgrounds, and cybernetic micro-interactions.

## Color Palette
- **Teal / Cyber Green (Primary)**:
  - `teal-500`: `#14b8a6`
  - `teal-600`: `#0d9488`
  - `teal-700`: `#0f766e`
- **Ruby / Red (Critical & Machine Tokens)**:
  - `red-500`: `#ef4444`
  - `red-600`: `#dc2626`
- **Amber / Alert Yellow (Pending & Warnings)**:
  - `amber-500`: `#f59e0b`
- **Carbon / Slate (Backgrounds & Surface)**:
  - Dark background: `hsl(210 24% 4.5%)` / `#0f1419`
  - Slate-900: `#0f172a`
  - Slate-950: `#020617`

## Typography
- **Sans-serif (UI & Navigation)**: Inter, Outfit, system-ui
- **Monospace (Code, Queries, Badges, Tokens)**: JetBrains Mono, Fira Code
- **Scale**: Dense rows with `leading-tight`, relaxed documentation with `leading-normal`.

## Component DNA
- **Cards**: `rounded-xl`, `border-border`, 1px subtle outlines, zero heavy shadows.
- **Buttons**: Tactile scaling on tap, 150ms ease transitions.
- **Badges**: Pill-shaped (`rounded-full`), monospace tags (PK in green, NOT NULL in teal).
- **LED Indicators**: Subtle pulsing dots for SSE live streams and service health.

## Voice & Tone
- **Error Messages**: Technical, precise, and actionable without being condescending (e.g., "Invalid column type identifier: alphanumeric only").
- **Success States**: Crisp and terse (e.g., "Table `users` created. REST API live at `/api/rest/users`").
- **Audit Logs**: Cryptographic, chronological, and objective.
